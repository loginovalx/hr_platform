# Кадры · Горький

Платформа муниципального подбора для хакатона. В одном приложении работают карьерная витрина, гостевые отклики, кабинет HR и анкеты обратной связи.

## Запуск демо

Требуется Node.js 24 или новее.

```sh
npm run dev
```

Откройте http://127.0.0.1:3000/hr и нажмите «Открыть демо-кабинет». В базе есть три вакансии, два профиля Марии Соколовой с разными контактами, отклик из архива, отказ на интервью, оформленный найм и анкета после увольнения. Новые данные сохраняются после перезапуска.

```sh
npm test
```

## Самостоятельное размещение

```sh
npm run build
SEED_DEMO=0 HOST=0.0.0.0 PUBLIC_ORIGIN=https://your-host.example npm start
```

Перед запуском передайте через окружение `ADMIN_PASSWORD` для роли `admin` и при необходимости `HR_PASSWORD` для роли `hr`. Роль администратора открывает оформление увольнений и ответы на анкеты бывших сотрудников. `PUBLIC_ORIGIN` задаёт канонический адрес за HTTPS-прокси. `DATA_DIR` указывает каталог SQLite и вложений. `SEED_DEMO=0` применяется при инициализации новой базы.

В самохостинге гостевые вакансии и анкеты доступны по прямым ссылкам. Опубликованное демо использует закрытый доступ по аккаунту и синтетические данные. Хостинговый вариант хранит записи в D1, а вложения в R2.

## Приём и разбор

- Форматы вложений: TXT, DOCX и PDF до 5 МБ. TXT и DOCX разбираются в приложении. В самохостинге для извлечения текста из PDF используется `pdftotext` (Poppler), если он доступен. Для PDF на демохостинге и сканов можно приложить оригинал и вставить текст вручную.
- Почтовые отклики вводятся вручную. Архив принимает JSON до 20 записей за запрос. Пример доступен в диалоге импорта, а отчёт показывает ошибки по строкам.
- Обработчик оценивает критерии по локальным правилам. Цитаты разрешаются на сервере, а решения и правки HR хранятся отдельно. Для будущего подключения модели предусмотрен обезличенный формат обмена в `examples/scoring.json`.
- Для анкет и уточнений приложение готовит персональные ссылки. HR отправляет их вручную и отмечает отправку анкеты в кабинете.

## Контракты

`openapi.yaml` описывает публичный API и кабинет HR. Примеры запросов, ответов и событий находятся в `examples/`.

Сохранение заявки, связанных ответов и события приёма выполняется транзакцией. Обработка события идемпотентна. Сервер защищает версии этапов и однократные ответы, а повтор запроса с тем же `Idempotency-Key` возвращает сохранённый результат.
